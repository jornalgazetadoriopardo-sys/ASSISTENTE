# Assistente: painel de atendimento de clientes

Um painel para acompanhar o status de cada peça de cada cliente de marketing digital (briefing, produção, aguardando aprovação, ajustes, aprovado, publicado), com mensagens de cobrança prontas para o WhatsApp. Inclui um agente semanal que usa o Claude para escrever o resumo da semana.

- **Tutorial completo:** [TUTORIAL.md](TUTORIAL.md)
- **Teste rápido:** `cd app && python3 -m http.server 8000` e abra <http://localhost:8000>
- **Agente sem IA (teste):** `cd agente && npm install && npm run teste`
